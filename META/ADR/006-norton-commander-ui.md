# ADR-006: Norton Commander UI Direction

## Status
Accepted

## Date
2025-01-15

## Context
The application needs a UI that is keyboard-friendly, information-dense, and reminiscent of classic file managers while remaining a modern resizable Windows application.

## Decision
The interface follows a Norton Commander-inspired design while remaining a modern resizable Windows application built with Avalonia.

## Requirements
- Dual-pane layout (left: browser, right: details panel)
- Adaptive layout — panes resize with window width
- Keyboard-friendly operation (F-keys, arrow keys, Enter, Backspace)
- Command bar with F-key labels
- Status line for feedback
- Clear navigation with breadcrumb context
